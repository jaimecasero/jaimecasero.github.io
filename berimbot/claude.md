Simple web application to learn capoeira music 

* Predefined capoeira beats
* Editable grid to create your own beats
* Selectable 3 level note velocity (ghost, normal, accent)
* Share your custom beat via link
* Predefined berimbau viola variations
* BPM selection for playing along beginners
* Dynamic cursor highlighting current note playing
* Volume/panning selection per instrument
* Designed for mobile phone using thumb finger
