Simple web application to learn drumming via drum sheet 

* Load predefined midi files
* Filter midi notes based on levels
* On screen pads for playing
* Metronome and bpm selection
* Play note or chord on canvas and dedicated degree buttons
* Play drums with midi device or keyboard 
* Designed for mobile phones to use thumb finger mainly
* Scoring system based on how similar user input is to midi file
