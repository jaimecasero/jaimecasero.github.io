Simple web application to compose drum grooves and share with frineds

* compose groove with table or select plus button
* select time signature
* select temp
* play/pause groove

html code at ./groovelab.html
css code at ./groovelab.css
js code at ./groovelab.js
service worker at ./sw.js
images under ./img

Once a feature/bug is implemented the service worker cache name must be updated with semantic versioning logic
